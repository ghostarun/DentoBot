## 5. Failure — Step 4A Target tooth dropdown cannot scroll

### Operator observation

On Step 4A, the **Target tooth** `QComboBox` (`targetToothComboBox`) could not
be scrolled to choose teeth lower in the list.

### Root cause

The active stage panel lives inside `workflowContentScrollArea`
(`widget_application.py` `_setupPersistentWorkflowShell`). Nested `QComboBox`
popups inside `QScrollArea` commonly lose mouse-wheel input to the parent
scroller and can render with an unbounded height that is hard to navigate.

### Failed fix (regression — entire workflow unusable)

First implementation (`ui_scroll_support.py` v1):

- Called `setWindowFlags(Qt.Popup | …)` on combo popup parent widgets during
  `showPopup`.
- Installed a broad scroll-area event filter that intercepted wheel events using
  `view.isVisible()` / `view.window().isVisible()` heuristics and a
  `showPopup` / `hidePopup` counter.
- **Operator report:** entire workflow became **not working, viewable, or
  selectable**.

**Likely failure mode:** `setWindowFlags` on the wrong widget in the Qt tree
can corrupt window hierarchy; stale “popup open” detection caused the scroll
area to swallow wheel events globally.

### Working fix (v2)

`ui_scroll_support.installScrollAreaComboBoxWheelGuards(scrollArea)` — safe subset:

1. **Configuration only:** `maxVisibleItems = 12`, list view
   `ScrollBarAsNeeded`, `ScrollPerPixel` for every `QComboBox` in the scroll
   content.
2. **Narrow wheel router:** `_ScrollAreaComboWheelCoordinator` installs an event
   filter on the scroll-area **viewport only**. It forwards wheel events when
   the cursor is over an open combo `QAbstractItemView` descendant; otherwise
   returns `false` (no interception).
3. **Explicitly forbidden** after regression: `setWindowFlags` on popup parents,
   `showPopup` / `hidePopup` monkey-patching, broad scroll blocking.

Wired from `widget_application.py` immediately after `scrollArea.setWidget(contentWidget)`.

### Test added

`test_workflow_scroll_area_installs_combo_popup_wheel_guards` — asserts install
call, no `setWindowFlags` / `showPopup` in scroll support module.

focused trio → **26 passed** at commit time.
