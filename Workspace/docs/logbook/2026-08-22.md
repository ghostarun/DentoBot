## 03:35 IST — Separate draft workspace logic

Added Step 6.3 Workspace Explorer. Logic chain: task min/max → deterministic
six-base Halton sequence → display units to SI → URDF FK → provisional TCP
origin → 5 mm non-adjacent AABB test → subsampled phantom/case TCP point
clearance → base-local VTK vertex cloud. Halton sampling avoids Cartesian-grid
explosion and random-run drift; it is not repeated IK. The first sample is the
current joint vector. The result node is cyan, parented to the robot base,
excluded from scene save, cleared when task limits change, and marked stale
when the base moves.

The initial 600-sample run rejected all poses because the known
`link-3`/`link-5` and `link-3`/spindle axis-aligned CAD boxes overlap at every
pose. MoveIt/FCL accepts the verified nonzero state, so those exact two pairs
are now excluded only from the coarse fallback. Remaining pairs still enforce
5 mm: 348/600 accepted and 252 rejected in 0.191 s. This is explicitly not an
SRDF allowed-collision or physical-safety claim.
