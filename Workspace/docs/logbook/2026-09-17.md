## Case Foundation grayed after segmentation review (operator report)

- **Observed:** Case Foundation controls stayed disabled with “Review the source
  CBCT segmentation…” although the operator had marked the segmentation
  `Reviewed` on the Segmentation stage.
- **Cause:** Review state is stored on the **inspection** segmentation
  (`inspectedSegmentation`). Case Foundation gates on the **planning**
  references (`teethSegmentation` + `inputVolume`), which are only set by
  “Use for Planning → Step 3”. Navigation to stage 3 did not perform that
  handoff.
- **Fix:** `_maybeAutoCommitInspectionForCaseFoundation()` adopts a reviewed
  inspection run when entering or refreshing Case Foundation (same commit path
  as the explicit button, including downstream invalidation confirmation).
- **Files:** `widget_scan_context.py`, `widget_navigation.py`,
  `widget_robot_scene.py`.
