### External guidance and analysis

- Current Docker documentation recommends Docker Desktop with its WSL2 backend
  for most Windows users and warns against running Docker Desktop integration
  and a separately installed Docker Engine/CLI together because they can
  conflict. It also recommends keeping source and bind-mounted data in the WSL
  Linux filesystem. Docker's Ubuntu instructions support Docker Engine from the
  official apt repository with the Compose plugin and systemd management.
  Microsoft documents systemd support in WSL.
- For DENTOBOT, both backends can satisfy the same runtime contract: Docker API,
  Compose v2, the pinned Linux image, Linux-filesystem bind mounts, WSLg mounts,

  maintenance an explicit DENTOBOT workstation responsibility.
