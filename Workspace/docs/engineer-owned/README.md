# Engineer-owned records

This folder separates the engineer's personal operating records from the
AI-maintained development controls under `Workspace/docs/`.

The protected set is:

- `DENTOBOT_Daily_Compass.docx` (local and Drive);
- `IITM Personal Work Journal` (Drive-native); and
- `IITM Dental Drilling Robot — Project Tracker` (Drive-native).

Agents must not read, edit, reconcile, move, export, or synchronize any of
these records unless the user explicitly names the artifact and action in the
current request. Generic development instructions—including resume, plan,
reconcile, update docs, Drive sync, close-day, and postmortem-sync requests—do
not authorize access.

`Workspace/docs/TASKS.md` is different: it remains the AI-maintained,
development-authoritative work order.

The matching Drive parent is `IITM Dentobot/Engineer-owned — manual only`.
Existing Drive file IDs must be retained during any explicitly requested move
or update.
