# Archived draft open-mouth phantom

This directory preserves the retired, generic BodyParts3D phantom logic and
its focused SlicerROS2 smoke script for historical explanation only.

The archive is not imported by `DENTOWorkflow`, is not a supported product
path, and is intentionally absent from `Testing/verification_matrix.json`.
Existing MRML scenes may still contain these nodes; production loading hides
them, and they never satisfy Case Foundation or Step 6 eligibility.
